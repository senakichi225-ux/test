## 0. 3種類に共通する考え方

1. **オーダーメイド（受注生産）**：注文を受けてから書く。作り置きをしない。
2. **書＋絵**：せなの強みである力強い書に、色のある絵（花・鳥・月など）を添える。
3. **襖の構造でつくる**：額に入れた書ではなく、**襖と同じつくり**で作品をつくる。これが「Beyond the Frame.」の具体的な形です。

```
  ┌───────── 縁（ふち）：作品ごとに木・色・仕上げを選ぶ ─────────┐
  │  ┌──────── 上張り：襖紙（鳥の子紙など）＋書・墨・絵 ────────┐ │
  │  │  下張り：和紙を何層も重ね、紙の張りと奥行きをつくる       │ │
  │  │  骨（組子）：軽い木の格子。作品の芯                         │ │
  │  └───────────────────────────────────────────────┘ │
  │                         ● 引手（余白の点・署名として使える）   │
  └──────────────────────────────────────────────────────┘
```

- 伝統的な本襖では下張りを何層も重ねます。**工程の名前・層の数・材料は、協力してくれる職人さんに確認してから**、作品の説明に使います。
- 裏面には、作品番号・作品名・制作年を記したラベルと、壁掛け金具を付けます。
- 署名は、作品の正面の落款（らっかん：印）と、裏面のラベルで行います。
- **漢字の意味は必ず辞書などで確認する。** 悪い意味・まちがった使い方の漢字や四字熟語を選ばない。

## 2. 各種類の詳しい内容

### A. 名前アート（Name Art）— あなたの名前を、漢字で

- **注文の流れ（案）**
  1. お客さんから名前（つづりと読み方）と、好きなもの・大切にしていることを聞く
  2. 音に合う漢字の組み合わせを**3案**考え、それぞれの意味を英語で説明する
  3. お客さんが1案を選ぶ
  4. 書いて、小さな絵（花・鳥・月など）を添えて仕上げる
  5. 選んだ漢字の意味を説明する**英語のメモ**と作品証明書を付けて送る
- **他との違い**：名前の漢字を書くサービスはすでに多くありそう（**未調査**。比較作品として出典つきで調べる）。和道では、**意味をていねいに選ぶ・絵を添える・襖の構造でつくる・証明書を付ける**ことで違いを出す。
- **注意**：名前・メールアドレスは個人情報。保存と管理はおうちの人と行う（`CLAUDE.md` §7）。
- **試作の順番**：**いちばん最初に作る。** 小さく安く、材料・工程・撮影・梱包・配送テストを一通り試せるから。

### B. 言葉アート（Word Art）— あなたが選ぶ言葉を、1〜4文字で

- 一文字（例：「和」「光」）、大切な言葉、願い、四字熟語など。
- **料金**：基本の価格は2文字まで。3文字目と4文字目は、1文字ごとに追加料金。
- 言葉の意味を英語で説明するメモを付ける。
- 構図の例：画面の下3分の1に文字を置き、上に余白と絵。

### C. 四字熟語ペア（Four-Word Pair）— ホテル・旅館のための2枚組

- **コンセプト**：本物の襖が2枚1組で使われるように、**四字熟語を2文字ずつ2枚に**書く（例：「花鳥｜風月」）。2枚のすき間も構図の一部。
- **注文の流れ（案）**：ホテルのイメージ・場所・大きさを聞く → **和道が用意した四字熟語の一覧**（意味の英語説明つき）から選んでもらう → 制作。
- **一覧にない四字熟語**を注文される場合は、**追加料金**がかかる（意味・使い方の確認と、構図を一から考える手間のぶん）。金額は [TBD]。
- **四字熟語の一覧（12個。2026-10-12 決定）**：データは `web/content/idioms.json`。意味と英語の説明は**まだ辞書で確認していない下書き**（確認したら `checked: true` にする）。

| グループ | 四字熟語 |
|---|---|
| おもてなし | 一期一会・以心伝心・千客万来 |
| 自然・季節 | 花鳥風月・春夏秋冬 |
| 願い | 笑門来福・身体健康・商売繁盛・福徳円満・交通安全 |
| 勢い | 天下無双・疾風迅雷 |

- **因果応報・唯我独尊**は、悪い意味に取られやすいので一覧に入れない（言葉アートでなら注文可）。
- 天下無双・疾風迅雷は強い言葉なので、静かな旅館より、レストラン・バー・ジムなどに向く。交通安全は、ホテルよりタクシー会社や車のお店に向く。
- **飾り方の提案書**を付ける：おすすめの間隔（例：3〜8 cm）、壁の高さ、照明の当て方。
- **注意**：ホテル・旅館への連絡と契約は**おうちの人と**。まずは小さな旅館・ゲストハウス・お店から。将来の襖アートドアにつながる。

## 4. 原価構造と価格の考え方

### 4-1. 原価の内わけ（1点あたり）

| 区分 | 項目 | 備考 |
|---|---|---|
| 材料 | 骨・芯材、下張り用の和紙、上張りの紙（鳥の子紙など）、糊、墨、文様紙 | 実際に買った金額を、使った割合で配分する |
| 部品 | 縁（木材・仕上げ）、引手、壁掛け金具、裏ラベル | |
| 表具の手間 | 職人さんの作業時間 × 時間あたりの対価 | **対価は職人さんと合意して決める**（安く見積もらない） |
| 書・制作の手間 | 書く時間・練習の紙 × 制作者の時間単価 | 未成年でも、事業の原価として時間を記録する |
| 証明書・印刷 | 証明書、ラベル、お手入れ説明書 | |
| 撮影 | 背景紙・照明などの費用を、作品数で割る | |
| 梱包材 | 箱、角の保護材、緩衝材、防湿袋 | 一点物はしっかりした梱包にする |
| 販売の費用 | 決済手数料（決済サービスの公式料率で確認）、ギャラリー経由の場合は販売手数料 | 価格に対する割合 |
| 送料 | 国内／海外（地域別） | **原則は別料金**（見積もりを出す）。込みにするかはテスト項目 |

### 4-2. 価格の決め方（式）

```
原価 C   ＝ 材料 ＋ 部品 ＋ 表具の手間 ＋ 書・制作の手間 ＋ 証明書 ＋ 撮影の配分 ＋ 梱包材
直販価格 P ≧ C × 3（一点物は C × 3〜4 ＋ 作品の価値を加える）
ギャラリー経由：ギャラリーの手数料を販売価格の50%とすると、受け取る額 ＝ P × 0.5 ≧ C × 1.5
→ 直販とギャラリーの価格を同じにしても、どちらでも赤字にならない
送料は別立て（地域ごとに見積もり）
```

- **販売価格は、直販とギャラリーで同じにする**（売る場所で価格を変えない。アートの一般的な考え方。ギャラリーとの契約時に確認）。
- 言葉アートの追加料金（3文字目・4文字目）は、1文字ぶんの手間と材料の増え方を実測して決める。

### 4-3. 原価の計算例（**すべて仮の数字。実測値で置き換える**）

数字を入れる練習のための例です。職人さんの対価や材料費は、まだ確認していません。

| 材料（骨・紙・糊・墨など） | ¥3,000 | ¥12,000 | ¥22,000 |
| 縁・引手・金具・ラベル | ¥2,000 | ¥11,000 | ¥22,000 |

| 証明書・撮影の配分 | ¥500 | ¥1,000 | ¥1,000 |

## 5. 作品証明書と作品番号のルール

### 一点物と限定作品の区別
| | 一点物（Unique） | 限定作品（Limited edition） |
|---|---|---|
| 定義 | 世界に1点。同じ構図は二度と作らない | 同じ図案で、決められた数だけ制作。1点ずつ手で仕上げる |
| 表記 | `Unique` | `Edition 3/30` |
| 作品番号 | `WADO-2026-WORD-U001` | `WADO-2026-XXXX01-E003`（いまは限定作品の予定なし） |
| 証明書 | あり（作品写真つき） | あり（エディション番号つき） |
| 追加制作 | しない | 上限の数（30）を超えて作らない。図案を終えるときは記録に残す |

### 作品番号の付け方
```
WADO-{制作年}-{種類}-{U=一点物 / E=限定}{連番3桁}
種類：NAME＝名前アート／WORD＝言葉アート／PAIR＝四字熟語ペア
例：WADO-2026-NAME-U001 / WADO-2026-WORD-U001 / WADO-2026-PAIR-U001
```

### 証明書に書く項目
作品名（英語・日本語）／作品番号／種類（一点物・限定とその番号）／制作年／素材と技法／寸法（cm と inch）／制作者／協力職人（ご本人の許可がある場合）／作品写真／発行日／署名と落款／お手入れの注意／発行者（kerokero）

## 6. 海外発送を考えたサイズ・重量・梱包（仮説）

> 配送会社の上限は**未確認**です（`research/logistics.json`）。必ず公式情報で確認します。

| | 名前アート | 言葉アート | 四字熟語ペア（1枚ずつ） |
|---|---|---|---|
| 梱包後のサイズ（仮） | 40 × 40 × 10 cm | 72 × 102 × 10 cm | 57 × 102 × 10 cm（×2箱 または 1箱にまとめる） |
| 長さ＋胴回り（仮） | 40＋2×(40＋10)＝140 cm | 102＋2×(72＋10)＝266 cm | 102＋2×(57＋10)＝236 cm |
| 容積重量の例（縦×横×高さ÷5000。式は会社ごとに確認） | 約3.2 kg | 約14.7 kg | 約11.6 kg |

- **大事な気づき**：国際宅配便では、薄くて大きい荷物は「実際の重さ」より「容積重量」で料金が決まることが多いです。言葉アート・四字熟語ペアの送料は、作品の重さではなく**箱の大きさ**で決まる可能性が高いため、梱包の厚みを薄く・小さくする工夫が原価に直結します。
- 梱包の基本（案）：防湿袋 → 角の保護材 → 表面を守る板（作品の面に触れない浮かせ方） → 箱の中で動かない固定 → 二重箱。木製の梱包材を使う場合は、輸出先の規制を確認します。
- 同梱するもの：証明書、お手入れ説明書（日本語と英語）、飾り方の案内（四字熟語ペア）。
