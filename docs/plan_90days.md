# 最初の90日間の行動計画（2026-10-12 〜 2027-01-10）

- 版：v0.1（2026-10-10）
- ゴール：**最初の壁掛けアートを試作し、少数を問い合わせ販売に出して、需要があるかを判断できる状態にする。**
- 前提：予算はシナリオ **M（約15〜25万円）** を基本にする（`docs/business_plan.md` §5）。S（約5万円）の場合は、★のついたタスクだけを行う。
- 学校との両立：1週あたりの作業は、平日に少し・週末に3〜5時間を目安にする。テスト期間（日付は学校の予定で確定）は作業を止める週として扱う。

---

## 90日後に判断すること（Decision Gate）

| 判断 | 条件（仮の基準。始める前に保護者と決める） | 次にやること |
|---|---|---|
| **進む** | 問い合わせ10件以上、そのうち販売 2点以上、粗利が目標以上 | 第2シリーズの制作、ギャラリーとの本格的な取引、サイトに決済を導入 |
| **作り直す** | 反応はあるが、販売につながらない（価格・サイズ・見せ方が合っていない） | 価格・サイズ・写真・売り方を1つずつ変えてもう一度テスト |
| **止める・方向転換** | 反応がほとんどない | ターゲット（国内・海外）、商品の形、伝え方を見直す |

## 毎週の決まりごと
- **日曜**：今週の作業・時間・材料・費用を作品台帳と原価シートに記録（10分）。
- **AI社員**：ニュースくん（毎朝の情報収集）、ケリー（水曜：英語の投稿案）、ピョン太（金曜：展示・コンテスト情報）、ケロ吉（月曜：提案先の候補）。
- **月初め**：ゲコ部長が前の月をまとめ、来月の3つの重点を決める。
