## 1. ブランドの完成コンセプト

| 項目 | 内容 |
|---|---|
| ブランド名 | **和道**（読み：わどう／英語表記：**WADŌ**） |
| タグライン | **Beyond the Frame.** |
| 使命（Mission） | 日本の襖を、世界で認められる現代アートへと発展させる。 |
| コンセプト | 日本の伝統を原点に、そこに込められた精神を新しい芸術として世界へ届ける。 |
| 名前に込めた意味 | **和 — Harmony**：日本の伝統と心、作品と空間のあいだの静かな調和／**道 — The Way**：職人が受け継いできた道と、襖が現代アートへ進む新しい道<br>※ブランド独自の解釈であり、正式な語源ではない（外部向けにもそう読める書き方にする） |
| 世界観 | 高級感・ミニマリズム・現代アート・日本の伝統と革新 |

### 「Beyond the Frame.」の意味づけ（ブランドの核）
1. **額縁を超える**：額装した書ではなく、**襖そのものの構造（下張りを重ねた紙の層・縁・引手）が作品の形になる**。縁は「額」ではなく、作品の一部。
2. **建具の枠を超える**：襖は「開け閉めする道具」から、「空間に置く現代アート」へ。
3. **国の枠を超える**：日本の住まいの中だけでなく、世界のギャラリー・住宅・ホテルへ。

### 普通の額装書道作品との違い（差別化）
| 観点 | 一般的な額装の書 | 和道 |
|---|---|---|
| 支持体 | 紙を額に入れる | **襖の構造でつくる**（木の骨＋何層もの下張り＋襖紙）。紙の張りと奥行きそのものが表現 |
| 枠 | 既製の額縁 | **襖の縁（ふち）**を作品の一部として設計（色・木・漆の仕上げを作品ごとに選ぶ） |
| ディテール | なし | **引手**を作品の「余白の点」や「署名」として使える |
| 表現 | 伝統的な書の再現 | 書の筆致を、現代アートの構図（余白・反復・抽象）と組み合わせる |
| 売り方 | 作品単体 | **作品証明書・作品番号・素材と技法の記録**つき。一点物と限定作品を明確に区別 |
| 物語 | 書家の作品 | 書き手＋表具師（襖職人）の**協働作品**。伝統技術の継承につながる |

## 4. 商品別の想定価格と原価構造（仮説）

> **ここに書く価格はすべて仮説です。** 市場価格・需要の調査はまだしていません。原価を実測し、比較作品の価格を調べ、反応を見てから決めます。

| 案 | 想定販売価格（仮説） | 価格の考え方 |
|---|---|---|
| C. MA（限定） | ¥38,000〜55,000（US$260〜380 目安） | 入口価格。原価の約3倍を下限にする |
| A. ICHI（一点物） | ¥180,000〜280,000（US$1,200〜1,900 目安） | 一点物の主力。原価×3〜4＋作品価値 |
| B. TSUI（一点物2枚組） | ¥420,000〜650,000（US$2,800〜4,400 目安） | 最上位。2枚の制作と梱包が必要 |

- 円とドルの換算は目安です。為替は公開の直前に確認します。
- 原価の内わけ（材料・職人さんの手間・書の制作・証明書・梱包・送料・決済手数料・ギャラリーの手数料）と計算式は、商品ドキュメントの §4 にあります。
- **販売経路で利益が変わる**ので、価格は「ギャラリーに卸しても赤字にならない」ことを条件に決めます。ギャラリーの販売手数料は一般に販売価格の4〜5割と言われていますが、実際の条件は相手ごとに確認します。

## 5. 初期費用を抑えたスタート方法（予算シナリオ）

予算はまだ決まっていないので、3つのシナリオを用意します。**金額はすべて仮の目安で、見積もりを取ってから確定します。**

| シナリオ | 予算の目安 | 内容 | 向いている状況 |
|---|---|---|---|
| **S：最小** | 約5万円以内 | 小品（MA）3点＋ICHI 1点の試作。撮影はスマホと自然光。SNSは無料のみ。サイトは今の Next.js のものを使い、決済なし（問い合わせで販売） | まず「作れるか・反応があるか」だけを確かめたい |
| **M：標準（おすすめ）** | 約15〜25万円 | S に加えて、ICHI 2点・TSUI 1点の試作、梱包と国際配送のテストを1回、簡単な撮影機材（背景紙・ライト）、作品証明書の印刷、ドメイン取得 | 販売テストまで90日でやり切りたい |
| **L：拡張** | 約50万円〜 | M に加えて、プロの撮影、展示会または小さな個展、少額の広告テスト、サイトに決済を導入 | M で反応があり、すぐ次の段階に進みたい |

### 費用を抑える工夫
- **受注生産**：一点物は、売れてから同じシリーズの次の作品を作る。限定作品は「最初の5点だけ」作り、残りは注文を受けてから作る。
- **試作は小さく**：まず MA（30cm角）で、材料・工程・梱包を確かめてから大きいものへ進む。
- **すでにあるものを使う**：公式サイトの土台（`web/`）、AI社員による調査・英文の下書き・企画。
- **協力者と分担**：表具の工程は、協力してくれている職人さんに相談する（手間に見合う対価を払う前提）。

## 7. SNS と Web サイトの販売戦略

### 基本方針
- **SNS は「世界観と過程」、Web は「信頼と問い合わせ」。** SNSで知ってもらい、Webで作品の詳細・証明書・発送の決まりを見て、問い合わせ・購入につなげる。
- **最初は「問い合わせで売る」**（Price on request／価格を明記した問い合わせフォーム）。高額のアートは、やりとりの中で信頼をつくるほうが自然。決済の自動化は、売れる手応えが出てから。

### Instagram（主なチャネル）
| 項目 | 方針 |
|---|---|
| アカウント名 | `wado` を含むIDの空きを確認（例：`wado.fusuma`）。**取得は保護者が判断** |
| 投稿の柱 | ① 制作過程（筆・刷毛・紙の層・縁を付ける手） ② 完成作品（余白の多い構図・斜めの光） ③ 襖とは何か（英語の短い説明） ④ 名前と理念（和＝Harmony／道＝The Way） |
| 頻度 | 週2〜3回（学校と両立できる量）。Reels は工程の15〜30秒 |
| 言葉 | 英語を主、日本語を併記。キャプションは短く、専門用語には英語の説明 |
| 顔 | せなさんの顔を出すかは保護者が判断。出さない場合は「手」と「作品」だけで世界観をつくる |
| 計測 | 保存数・シェア数・プロフィールへのアクセス・リンクのクリック・DMの数 |

### Web サイト
- 構成とデザインは [`docs/website_plan.md`](website_plan.md)。
- 作品ページは**美術館のキャプション**の書き方にそろえる（作品名／制作年／素材と技法／寸法 cm・inch／一点物か限定か／証明書の有無）。
- 価格は「表示する」か「Price on request」かを作品ごとに選べるようにする（テスト項目）。

### ギャラリー・デザイナーへの直接提案
- AI社員のケロ吉が候補と紹介文を下書きし、**連絡するかどうか・連絡方法は大人と決める**。
- 提案資料（ポートフォリオPDF）は、試作作品の写真ができてから作る。

## 9. 想定されるリスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| **輸送中の破損** | 一点物は代わりがない | 梱包の落下テスト、保険つきの配送、破損時の方針（写真での確認→修理または返金）を事前に決める |
| **紙の反り・伸び縮み**（気候差） | 品質への不満 | 試作を乾燥・湿気の環境で数週間置いて確かめる。お手入れ説明書 |
| **価格が安すぎる／高すぎる** | 赤字、または売れない | 原価の実測、比較作品の調査、価格表示のテスト。ギャラリーに卸しても赤字にならない価格 |
| **名前（和道／WADŌ／WADO）の商標の重なり** | 名前の変更、使用の差し止め | ロゴ・名刺・印刷物を作り込む前に商標を調べる。専門家への相談（保護者） |
| **職人さんの負担・制作能力の限界** | 納期遅れ、関係悪化 | 受注生産、限定数を小さく、適正な対価、無理な納期を受けない |
| **未成年の契約・お金の扱い** | 契約の有効性、トラブル | 契約・決済・アカウントは保護者名義。作品の権利の扱いを家族で決めておく |
| **作品の模倣・写真の無断使用** | ブランドの価値が下がる | 作品番号と証明書、作品写真のクレジット表記、公開する画像の解像度を抑える |
| **「伝統」の誇張・不正確な説明** | 信頼を失う | 技法・素材・歴史の説明は、職人さんや一次資料で確認してから書く |
| **一点物の返品** | 再販売が難しい | 返品の条件（破損・説明と違う場合など）を事前に明記。購入前の写真・寸法の確認を丁寧に |
| **学校との両立** | 計画が止まる | 90日計画は週単位で、テスト期間は休む前提で組む |

## 10. 管理する指標（KPI）

**壁掛けアート事業と、ドア事業は、別々に管理する。**

### 制作
| 指標 | 意味 | 記録場所（予定） |
|---|---|---|
| 制作数（試作・完成・販売可能） | どれだけ作れたか | 作品台帳 `docs/templates/works_registry.csv` |
| 1点あたりの制作時間（書・表具・仕上げ） | 原価と納期の根拠 | 原価シート |
| 不良率・やり直し数 | 品質の安定 | 作品台帳 |
| 1点あたりの実際の原価 | 価格の根拠 | 原価シート |

### 販売
| 指標 | 計算 | 目安（仮説。90日後に見直す） |
|---|---|---|
| 問い合わせ数 | 作品への問い合わせの件数 | 90日で10件 |
| 成約率 | 販売数 ÷ 問い合わせ数 | 20〜30% |
| 平均販売価格 | 売上 ÷ 販売数 | — |
| 粗利率（商品別） | （販売価格 − 原価）÷ 販売価格 | 一点物 60%以上、限定 55%以上を目標 |
| 経路別の利益 | 直販とギャラリーのそれぞれ | ギャラリー経由でも黒字 |

### 認知・需要
| 指標 | 意味 |
|---|---|
| Instagram の保存数・シェア数・プロフィール訪問 | 世界観が届いているか |
| ウェイティングリストの登録数（役割・国の内わけ） | 誰が関心を持っているか |
| ギャラリー・デザイナーからの返信率 | B2B の可能性 |
| サイトの訪問 → 問い合わせ率 | サイトが信頼をつくれているか |
