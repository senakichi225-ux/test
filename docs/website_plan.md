# 和道（WADŌ）公式サイト — 構成とデザイン方針

- 版：v0.1（2026-10-10）
- 目的：**「作品を見て、信頼して、問い合わせる」まで**を、静かで迷わない流れで実現する。
- 前提：まだ作品の写真・販売の実績はない。最初は**作品の構想（試作中）**として正直に見せ、ウェイティングリストと問い合わせを集める。決済は売れる手応えが出てから（`docs/business_plan.md` §7）。

### ナビゲーション
`WADŌ`（ロゴ） ｜ Works ｜ Story ｜ Commissions ｜ Contact ｜ EN / JA

### 作品データの持ち方
- `web/content/works.json`（zod で検証）に、シリーズと作品を記録する。作品番号は作品台帳（`docs/templates/works_registry.csv`）と同じものを使う。
- `status`：`concept`（構想）／`prototype`（試作中）／`available`（販売中）／`reserved`（商談中）／`sold`（売約済み）
- `price`：`null` のときは「Price on request／価格はお問い合わせください」を表示。**構想・試作中の作品には価格を出さない**（価格は仮説のため）。
- 写真がない作品は、CSS で描いたイラストを「Illustration」と明記して表示する。

## 2. デザイン方針

### 2-1. 考え方
- **高級ギャラリーの余白**：1画面に伝えることは1つ。作品のまわりに、作品と同じくらいの余白を取る。
- **作品が主役**：UIは色を持たない。色があるのは作品だけ。
- **日本らしさは「素材・筆致・構造・余白」で表す**：和柄・金・朱の装飾、筆文字風フォント、桜・富士などのモチーフは使わない。
- **美術館のキャプション**：作品の情報は、美術館の壁のラベルと同じ順序と書き方にそろえる。
- **英語が先**：海外の人が理解できる英語を主にし、日本語の言葉（*fusuma, hikite, sumi, washi*）には短い英語の説明を添える。

### 2-2. 色（デザイントークン）
| トークン | 色 | 用途 |
|---|---|---|
| `sumi` | `#161513` | 墨黒。文字・ロゴ・暗いセクションの背景 |
| `washi` | `#F3EFE6` | 和紙アイボリー。基本の背景 |
| `washi-deep` | `#E8E2D5` | セクションの切り替え、作品の台座 |
| `usuzumi` | `#6E6962` | 薄墨。補足の文字 |
| `nezumi` | `#A8A39A` | 鼠色。罫線・キャプションのラベル |
| `line` | `#D9D3C7` | 細い罫線 |
| `shu` | `#A8432E` | **エラー表示だけ**に使う（装飾には使わない） |

- 以前の案の `ai`（藍）・`kin`（金）は使わない。リンクは下線で示す。

### 2-3. 文字
| 役割 | 欧文 | 和文 | 使い方 |
|---|---|---|---|
| 見出し・ロゴ | Cormorant Garamond（300〜500） | Zen Old Mincho | 大きく・細く・行間は詰め気味。使いすぎない |
| 本文・UI | Hanken Grotesk | Zen Kaku Gothic New | 本文は16〜18px、1行は欧文で約65文字まで |
| キャプション | Hanken Grotesk（小さく・字間を広く・大文字） | Zen Kaku Gothic New | 作品の情報、ラベル |

- ロゴ：文字だけのワードマーク「WADŌ」。Cormorant Garamond、字間を広く。マクロン（ー）は細い一本線として見せる。
- 数字（寸法・作品番号）は等幅の数字（`tabular-nums`）でそろえる。

### 2-4. レイアウト
- 最大幅 1280px、左右の余白は最低 20px（スマホ）〜 64px（PC）。
- グリッドは非対称を許す（作品を中心からずらし、反対側に余白とキャプション）。
- セクションの上下の余白は大きく（PCで 128〜192px）。
- ボタンは四角で、線か墨の塗り。角丸・影は使わない。

### 2-5. 写真の表現（作品写真ができたら）
| カット | 目的 | 撮り方 |
|---|---|---|
| 正面 | 作品そのもの | 和紙アイボリーかグレーの壁、正面から、自然光か柔らかい光 |
| 斜めからの光 | 紙の質感と影 | 横から低い角度の光。紙の層・筆の跡の凹凸を見せる |
| ディテール | 職人の手仕事 | 縁の角、引手、紙の重なり、落款を近くで |
| 設置イメージ | 空間での大きさ | 実際の部屋の壁。人や家具と並べて大きさが分かるように |
| 工程 | 物語 | 手元だけ（顔を出すかは保護者が判断） |

- 加工は控えめ（色を盛らない、フィルターを使わない）。画像は WebP/AVIF、公開する解像度は抑える（無断利用の対策）。

### 2-6. 動き
- ゆっくりのフェードだけ。ヒーローの作品は、光が横から差していく1回だけの演出。
- `prefers-reduced-motion` のときは動かさない。

## 3. 各ページの中身（文言の方針）

### Home
1. **Hero**：「Beyond the Frame.」＋1行の説明（Fusuma, reimagined as contemporary art.）＋代表作のイラスト（写真ができたら差し替え）
2. **Statement**：使命の一文（日本の襖を、世界で認められる現代アートへ）
3. **First collection**：名前アート／言葉アート／四字熟語ペアの3種類（オーダーメイド。状態：構想・試作中）→ Works へ
4. **Built like a fusuma**：襖の構造の図（骨・下張り・上張り・縁・引手）。額縁との違い
5. **The name**：和＝Harmony／道＝The Way（「ブランド独自の解釈」と注記）
6. **Waitlist**：最初の作品の公開をお知らせ

### 作品ページ（キャプションの形）
```
Word Art — “Wa”                  ← 作品名
2026                             ← 制作年
Sumi ink on washi; fusuma construction, cedar edge   ← 素材と技法
60 × 90 × 2 cm / 23.6 × 35.4 × 0.8 in               ← 寸法
Unique · Certificate of authenticity                 ← 種類・証明書
Price on request                                     ← 価格
[Inquire about this work]                            ← 問い合わせ
```

### Commissions（襖アートドア）
- 「将来の商品。いまは建築家・デザイナーとの対話を始める段階」と明記。
- 特注の流れ（予定）：相談 → 現地の寸法と開閉方式の確認（現地の施工者） → デザイン提案と見積もり → 着手金 → 制作 → 輸送 → 現地施工 → お手入れ・修理の案内。
- 責任範囲（予定）：和道＝デザイン・制作・梱包／依頼主側＝現地の寸法確認・施工・建築上の確認。**正式な条件は契約時に決める。**

### Shipping & Care（下書き）
- 発送：国内・海外。送料は地域ごとに見積もり。保険つきの配送。
- 支払い：（未決定）問い合わせ後に案内。
- 返品：一点物の性質上、原則として返品不可。ただし破損・説明と異なる場合は対応（条件は公開前に確定）。
- 破損時：到着後○日以内に写真で連絡 → 修理または返金（条件は公開前に確定）。
- お手入れ：直射日光・暖房・湿気を避ける、紙に触れない、乾いた刷毛でほこりを払う。
